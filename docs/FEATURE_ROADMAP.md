# План развития Aimo

Ориентир — польза новичку, достоверность наблюдений и стабильная тренировка.
Следующее мероприятие пока не задано; старые веса жюри не используются.

| Статус | Задача | Польза и условие готовности |
| --- | --- | --- |
| Выполнено | Разделение исходников, тестов и материалов | Понятные области src/app, coach, ai, skills; сборка исключает тесты и архив. |
| Выполнено | Границы доверия локальной модели | Ввод/история отделены от system, вывод проверяется до UI, есть тесты атак и обычных запросов. Ограничения — SECURITY.md. |
| Выполнено | Упорядоченная работа агентов | Пять ролей, короткие инструкции, области файлов и профильные команды тестов; архив не нужен для старта. |
| Следующая | Проверки на iPhone и Android | Для каждого навыка записать устройство, ракурс, частоту позы, пропуски и ложные повторы. Минимум — реальный основной сценарий чеканки. |
| Следующая | Оценка Qwen на настоящей модели | Отдельно измерить обычный разговор, ложные блокировки и атаки; фикстуры unit-тестов не считать такой оценкой. |
| Запланировано | Отзывчивость при тяжёлом анализе | Замерить задержки, затем вынести синхронную позу в worker; очередь кадров не растёт, камера/LLM уступают приоритет позе. |
| Запланировано | Продолжение незавершённого шага | Человек явно выбирает продолжение; незавершённый повтор не переносится, измеренные итоги сохраняются. |
| Запланировано | Практика одной наблюдаемой ошибки | Предложить существующий шаг по реальному повторяющемуся наблюдению; не создавать упражнение из текста LLM. |
| Запланировано | Готовность к работе без сети | Раздельные статусы оболочки, зрения, Piper и Qwen; подтверждать пробным запуском без сети. |

Для новой задачи: проблема пользователя → ограниченный сценарий → владелец
файлов и контракт → измеримый результат → проверки. Не добавлять сервер,
обязательные внешние API, метрики точности или рост нагрузки без обоснования.
