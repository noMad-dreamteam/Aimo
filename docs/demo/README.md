# Локальные видео для проверки

Для воспроизводимой проверки подготовь вертикальное видео чеканки: 9:16,
30–60 секунд, хороший свет, контрастный мяч, всё тело в кадре.
Стойка 3 секунды → 6 подъёмов без мяча → отдельные касания → серии.
Проверь файл через «Открыть видео» и запиши устройство/результат в ../TEST_PLAN.md.
Это реальный анализ выбранного файла; синтетическое демо — отдельный режим.

Видео остаётся на устройстве и не входит в публикацию. Узнаваемых людей без
их согласия в репозиторий не добавлять. В комплекте проекта тестового видео пока нет.
