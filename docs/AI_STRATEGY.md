# ИИ и рабочий журнал Aimo

Текущая стратегия: зрение и чистые правила определяют факты, необязательная
локальная Qwen формулирует текст. Кадры модели не передаются. История остаётся
на устройстве. Подробности — ARCHITECTURE.md и SECURITY.md.

Старый журнал сохранён в [архиве](archive/2026-vibehack/AI_STRATEGY.md).
Его не требуется читать для каждой задачи. Новая запись содержит решение,
проверенные команды и оставшиеся ограничения; критерии прошлого конкурса не применяются.

### Защита
Добавлен src/ai/safety.js. Правила отделены от вопроса, профиля, истории и
сохранённых описаний. Данные передаются JSON user-сообщением; историческая
роль не становится ролью API. Известные инъекции/управляющие токены отсекаются,
недоверенный вывод проходит общий и предметный валидатор до UI/речи/истории.
Сырые токены больше не показываются: это увеличивает ожидание отображения,
но исключает кратковременный показ уже отклонённого текста.
LLM не получает tools и не управляет устройствами; боль остаётся на правилах.
Строгий JSON плана исключает посторонние поля и текст вокруг объекта.

Корпус: 12 атак и 12 обычных запросов, плюс проверки истории, роли, профиля,
итога, границ размера и вывода. Это не замер устойчивости реальной Qwen к
произвольным атакам. Источник: [OWASP Prompt Injection Prevention](https://cheatsheetseries.owasp.org/cheatsheets/LLM_Prompt_Injection_Prevention_Cheat_Sheet.html),
прочитан 30 октября 2026. Полные ограничения — SECURITY.md.

## 30 октября 2026 — аудит полномочий, инструментов и подтверждений
Проверены Least Privilege, Tool Validation, Human-in-the-loop и Trust Boundaries.
Два исходных пробела: удаление локальных данных без второго подтверждения и
ролевые ограничения кодирующих агентов только в инструкциях. Проверка messages
допускала произвольный system при правильной форме массива; сообщения TTS worker
с null/NaN/лишними полями не были полностью проверены до работы runtime.

Изменения: action-policy проверяет параметры до побочных эффектов, удаление
чата/всех чатов/прогресса/модели/голоса требует отдельного системного диалога.
Вызовы startLive из выбора навыка идут через общую точку запуска, публичная
функция тоже проверяет параметры. initChat повторно обновляет контекст без
дублирования DOM-обработчиков, иначе один клик мог запрашивать несколько подтверждений.
Builders выпускают неизменяемые requests с регистрацией в WeakSet; JSON-копия
не проходит границу клиента. Каталог system — только из исходников, budget
и model id ограничены. Tool/function-call ответы отклоняются, executor у Qwen
не появился. Worker проверяет схему до кеша/runtime.

В .codex/config.toml добавлены 7 профилей: read-only review по умолчанию,
ограниченные пути для каждой роли, сеть команд выключена, .env/.env.*, ключи
и .aws закрыты. Новые поддерживающие конфиг сессии запрашивают эскалации
у человека (approvals_reviewer=user); наследуют core-окружение и безопасный PATH.
Для работоспособности Node/Git разрешено только чтение установленного runtime,
системного macOS toolchain и openssl.cnf; личные Git-конфиги отключены.
