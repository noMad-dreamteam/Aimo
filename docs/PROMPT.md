# Aimo — текущая спецификация продукта

Aimo — приватный тренер для новичка. Цель: понятная тренировка на телефоне с
подсказками по тому, что удалось наблюдать. Развиваем продукт после первого
конкурса; конкретная программа следующего участия пока не определена.
Старый конкурсный промпт сохранён в archive/2026-vibehack/PROMPT.md.

## Основной сценарий
Локальный профиль → чат о цели → навык/маршрут → эфир с камерой → пошаговые
подсказки и измерения → итог в чате → сравнение сохранённых результатов.
Интерфейс и ответы на русском. Главный проверочный сценарий — обучение чеканке.
Есть десять навыков; новые добавляются только как проверенные модули измерений.

## Обязательное поведение
- Без аккаунта сервера, платежей и API-ключей; данные профиля, чатов и истории на устройстве.
- Камера/микрофон по явному действию; отказ и отсутствие возможностей объясняются в интерфейсе.
- Видео не записывается, не отправляется и не передаётся LLM.
- SpeechRecognition может использовать сервис браузера: пользователь видит пояснение перед включением.
- Правила определяют измерения и уроки; LLM только формулирует и предлагает проверяемый маршрут по каталогу.
- Демо явно помечено и не становится результатом. История камеры и файла не смешивается при сравнении.
- При отсутствии реальной детекции мяча метрика — подъёмы стопы, а не касания.
- Подсказки спокойные, ошибки подтверждаются наблюдениями, речь не перебивается новой фразой.
- Боль, фактические результаты, согласие и действия контролируются правилами.
- Пауза, завершение и уход отменяют запросы и освобождают устройства/workers.
- Непроверенный вывод модели не показывается и не озвучивается.

## Условия качества
Проверяем реальную пользу новичку, воспроизводимость счёта, отзывчивость,
доступность, защиту данных и устойчивость к недоверенному вводу.
Не оптимизируем задачи под старые веса жюри. Не обещаем точность, которую
не измерили. Цель позы на телефоне — не менее 8 к/с с приоритетом над LLM и объектами.
