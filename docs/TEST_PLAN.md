# Приёмка Aimo

## Автоматические проверки

| Команда | Область |
| --- | --- |
| npm run test:app | Камера, звук, очередь, хранилище, модельный manager, viewport/tabbar |
| npm run test:coach | Движения, 10 навыков, мяч, уроки, ошибки, ритм, прогресс и ответы правил |
| npm run test:ai | Промпты, маршруты, проверка ответов и доверия |
| npm run test:security | 14 тестов: известные атаки/обычные вопросы, граница клиента, права действий, подтверждения и TTS worker |
| npm run test:offline | Service Worker: офлайн и отказ записи кеша |
| npm run check | Синтаксис → все тесты → сборка → ссылки, manifest, SHELL, состав dist |
| npm run check:browser | Интерфейс, смена чатов, жизненный цикл и безопасность до показа |
| npm run check:permissions | 7 локальных профилей Codex: разрешённые/запрещённые пути и фиктивный .env; требует macOS и Codex CLI |

Браузерной приёмке нужен локальный сервер (`npm run dev`) и отдельно
установленный Playwright с Chromium. Параметры AIMO_BASE_URL,
AIMO_PLAYWRIGHT_MODULE и AIMO_BROWSER_EXECUTABLE описаны в README.
Для собранного сайта: AIMO_BASE_URL=http://127.0.0.1:4173/dist/.

## Последний подтверждённый результат — 30 октября 2026
266/266 unit-тестов PASS. 51 браузерная проверка PASS на ширинах 390 и 1280 px.
Добавлены отказ неверного запуска через bus и публичный startLive,
отмена/подтверждение удаления и защита от возвращения удалённых чатов поздним ответом.
Дополнительно проверены светлая тема при тёмных системных настройках,
автоматическая тема, чёрная подпись «Новый чат» и название «Танцы Тикток».
Проверяется смена системной темы без перезагрузки, затемнение нижней панели
в каталоге/прогрессе/профиле обеих тем и его отключение при открытой клавиатуре.
Отдельное сравнение до/после подтвердило одинаковые свойства 23 компонентов
тёмной темы и прежний фон нижней панели чата. Новое затемнение других вкладок
в это сравнение не входит. Скриншоты: /private/tmp/aimo-theme-refinement/.
Собрано 55 runtime-файлов; проверены 181 локальная ссылка и покрытие модулей
офлайн-оболочкой. Синтаксис 81 JS-файла PASS. TOML конфигураций агентов
разбирается Python tomllib. На macOS семь профилей прошли реальные проверки
файловых разрешений; 9 AI-тестов прошли внутри aimo-coach-llm, проверка синтаксиса —
в aimo-root с системным PATH и отключёнными личными Git-конфигами.

Камера — canvas-дорожка, модель — подменённый ответ. Проверки не подтверждают
точность на людях, защиту от всех инъекций или скорость реального устройства.
Исторические прогоны: archive/2026-vibehack/TEST_PLAN.md.
