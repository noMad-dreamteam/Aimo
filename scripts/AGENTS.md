# Инструменты проекта
- Сборку запускает только root, последовательно. dist/ содержит только runtimeFiles(), без тестов, архивов и инструкций.
- Пути должны работать на GitHub Pages в /Aimo/, а не только в корне домена.
- check-site проверяет импорты, workers, manifest, SHELL и отсутствие закрытых файлов.
- Браузерная приёмка использует отдельный профиль и поддельную камеру; не трогает личные вкладки и устройства.
- Скрипты должны сохранять ненулевой код выхода проверок. Секреты и пользовательские данные не печатать.
