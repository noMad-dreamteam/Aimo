# Интерфейс и интеграция
Читай только затронутые модули и tests/app/. Общие ограничения — в корневом AGENTS.md.
- main.js соединяет модули; live.js владеет поколением запуска, камерой и RAF; store.js — форматами локальных данных.
- DOM создавай через textContent/createElement. Не вставляй сообщения пользователя или LLM через innerHTML.
- send/askQuestion: проверка ввода до LLM и действий, боль остаётся на правилах.
- Токены LLM буферизуются до валидации; запрещённый текст не показывать и не озвучивать даже временно.
- При смене чата, выходе и старте эфира отменять запрос; старый ответ не восстанавливает удалённые данные.
- Сохраняй ключи localStorage и совместимость истории. Миграция данных требует отдельного теста.
- Доступность кнопок проверять обычным кликом. Не скрывать дефект через force/dispatchEvent в приёмке.
- Проверки: npm run test:app; для потоков чата также npm run test:ai и браузерный сценарий.
