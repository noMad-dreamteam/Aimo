# Правила и зрение
- Математика и переходы — чистые функции: не менять предыдущий state, координаты и историю.
- Не засчитывать дрожание, удержанную позу как повтор, потерю человека/паузу как удержание.
- Сброс трекинга сохраняет итоговые числа, но удаляет незавершённое движение и устаревшие объекты.
- Только sports ball передаётся трекеру мяча. Без позы/мяча не выдумывать наблюдения.
- Сохраняй контракт analyze: quality/framing, motion, metrics, lesson, feedback, objects, timing.
- Перед изменением MediaPipe API проверь Context7 или закреплённые исходники; version/CDN не обновляй попутно.
- Проверки: npm run test:coach; синтетическое демо не подтверждает точность на людях и частоту на телефоне.
